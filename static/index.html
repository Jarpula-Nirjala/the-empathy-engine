          Processing Pipeline
          
How It Works

          
Six-stage pipeline from raw text input to emotionally modulated audio output with full analytics.

        

        

          

            
01

            

              
Stage 1 · Input

              
Text Acquisition & Preprocessing

              
User text is received via the Emotion Studio interface or REST API. Input is validated (1–5000 characters), tokenized into sentences using NLTK punkt, and character/word/sentence metrics are computed for the UI.

              
    
                
  • NLTK sentence tokenization for per-sentence analysis
    • 
                
  • Sample corpus available for all 7 emotion categories
    • 
                
  • Optional manual emotion override before processing
    • 
              

            

          

          

            
02

            

              
Stage 2 · Classification

              
Neural Emotion Classification

              
The j-hartmann/emotion-english-distilroberta-base transformer model performs inference on the full text and each individual sentence, returning calibrated probability scores across all seven emotion classes.

              
    
                
  • DistilRoBERTa architecture — 66M parameters, ~250MB model
    • 
                
  • Primary emotion + confidence score (0.0–1.0)
    • 
                
  • VADER sentiment fallback if transformers unavailable
    • 
              

            

          

          

            
03

            

              
Stage 3 · Mapping

              
Intensity Scoring & Voice Mapping

              
Detection confidence linearly scales vocal parameters from neutral baseline. Each emotion defines speed, pitch shift (semitones), volume (dB), and pause factor values that are intensity-scaled before synthesis.

              
    
                
  • At confidence 0.5 → 50% modulation applied
    • 
                
  • At confidence 1.0 → 100% modulation applied
    • 
                
  • Intensity labels: low (<0.4), medium (0.4–0.7), high (>0.7)
    • 
              

            

          

          

            
04

            

              
Stage 4 · Markup

              
SSML Generation & Voice Parameters

              
Speech Synthesis Markup Language is constructed with prosody tags, emphasis on high-weight tokens, inter-sentence break timing, and per-sentence prosody when emotions differ across sentences.

              
    
                
  • <prosody> rate, pitch, volume modulation tags
    • 
                
  • <emphasis> on ALL-CAPS and emotion keywords
    • 
                
  • Dashboard gauges display computed vocal parameters
    • 
              

            

          

          

            
05

            

              
Stage 5 · Synthesis

              
Speech Synthesis & Audio Post-Processing

              
Google Text-to-Speech generates base audio per sentence. pydub applies frame-rate speed changes, pitch shifting, volume adjustment, and configurable silence gaps between sentences.

              
    
                
  • Per-sentence synthesis with individual emotion params
    • 
                
  • ffmpeg-powered MP3 encoding via imageio-ffmpeg
    • 
                
  • UUID filenames with automatic cache rotation (10 files)
    • 
              

            

          

          

            
06

            

              
Stage 6 · Delivery

              
Analytics, Playback & Export

              
Results are delivered through dashboard charts, heatmap visualization, sentence timeline, custom audio player with live waveform, JSON report export, and A/B comparison mode.

              
    
                
  • Radar, bar, and donut charts update in real time
    • 
                
  • Compare endpoint generates flat vs emotional audio pair
    • 
                
  • Processing time displayed in milliseconds
    •
